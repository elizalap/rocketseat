## 💻 Sobre o projeto

Agente IA utilizando o [CrewAI](https://www.crewai.com/) feito na aula "IA na prática".

Trata-se de um caso de uso para explorar as tecnologias de Inteligência Artificial, utilizando diversas libs e recursos como Yahoo Finance, GPT da OpenAI e DuckDuckGo search. 

A ferramenta tem como finalidade buscar, analisar e resumir preços das ações e notícias para gerar um relatório sobre ela.
